BUG FIXING CHALLENGE LEADERBOARD
================================

WHAT IS INCLUDED
- index.html: leaderboard page
- style.css: page design and responsive layout
- dashboard.css: vertical marks dashboard styling
- script.js: add/edit/delete, automatic ranking and CSV export
- Click "Show dashboard" to open the marks dashboard.
- The dashboard can show all scores together or filter by Set A or Set B.

HOW TO OPEN
1. Extract the ZIP file.
2. Open the extracted bug_fixing_leaderboard folder.
3. Double-click index.html, or open it with Chrome/Edge.
4. No installation, server, internet connection or database is required.

HOW TO ENTER STUDENT MARKS
1. In the "Add / Update Student Marks" section, enter the student's unique ID.
   Example: PY001
2. Enter the student's full name.
3. Select the question paper set: A or B.
4. Enter the student's final verified total out of 100.
5. Click "Add Student Score".
6. The student appears in the leaderboard and ranking is calculated automatically.
7. Repeat for each participant.

IMPORTANT MARKS WORKFLOW
- Evaluate Set A answer sheets with the Set A answer key.
- Evaluate Set B answer sheets with the Set B answer key.
- Add the marks for the 10 easy, 10 medium and 10 hard questions.
- Verify the total before entering it in this leaderboard.
- This app stores the final total only; it does not calculate marks question-by-question.
- A maximum of 100 and minimum of 0 are allowed.

EDIT / DELETE
- Click Edit beside a student to correct the name, set or score, then click Update Student Score.
- Click Delete to remove one entry after confirmation.

LEADERBOARD
- Highest score appears first.
- Students with equal marks share the same rank.
- The marks dashboard shows a vertical graph with a fixed 0–100 score range.
- Use the dashboard filter to view the combined scores or only Set A or Set B.
- The app does not automatically apply a tie-break test. Organizers should apply the event's announced tie-break rule separately and update the final scores/ranking if required.

BACKUP
- Click Download CSV to save an Excel-compatible backup.
- Download a backup after entering and verifying marks.
- Use the same browser and computer during the event. Data is stored in that browser's local storage, not in an online database.
- If you open the app on another computer or browser, the entries will not automatically appear there.
- Do not clear browser data before exporting the CSV.

RESET
- "Delete all leaderboard data" clears every entry from this browser.
- Use only after downloading a backup, if required.

SUGGESTED EVENT PROCEDURE
1. Prepare and print the Set A and Set B answer keys before the event.
2. After the 2-hour test, collect all answer sheets.
3. Evaluators check each paper using its matching answer key.
4. Record the verified total out of 100 on the organizer's master mark sheet.
5. A second organizer verifies the scores and student IDs.
6. Enter each verified score in this app.
7. Download the CSV backup.
8. Project the leaderboard and announce the top three.

PRIVACY
This is a simple offline browser tool. Anyone using the same browser profile on this computer may be able to view its saved leaderboard. Do not enter sensitive personal information.
